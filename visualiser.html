In words

  1. Preprocess each image the way its branch needs (crop, resize or letterbox; the scene is never cropped on LOCO).
  2. Extract features with frozen pretrained networks (WideResNet-50-2, PDN-S teacher, DINOv2). They are never updated.
  3. Compare with normal: each branch has learned what normal looks like from normal images of the category only (a patch memory, a student network, a reconstruction decoder, a memory of normal part arrangements).
  4. Score: the mismatch becomes an anomaly map and one image score per branch.
  5. Normalize each branch score with held-out normal images, so the four scales are comparable.
  6. Fuse: the full model takes the maximum, so one branch with strong evidence is enough.
  7. Evaluate: labels are used only here, to compute image AUROC (and, from the maps, the localization metrics).
